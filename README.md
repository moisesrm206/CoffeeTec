Descargar laragon o xammp para el uso de 'Laravel'
(recomendacion): Usar laragon, ya que es mucho mas sencillo de instalar, configurar y administrar los proyectos, pero la desventaja es que aunque es open source, cada que lo abres te muestra una ventana pidiendo que apoyes donando dinero para el proyecto

Xammp no tiene eso, pero puede ser complicado de configurar correctamente php, solo si se quiere usar la versionmas reciente de laravel, pero podriamos trabajar sin problemas con la version anterior, y entonces no habra ningun problema.
